# 04. Kế hoạch frontend

## Trạng thái

Kế hoạch בלבד. Chưa triển khai.

## Công nghệ dự kiến

- TypeScript.
- Phaser cho phần game 2D.
- React cho menu và UI ngoài game.
- Vite cho development và build.
- Zustand hoặc Redux Toolkit cho state.

## Module dự kiến

- `scenes`: boot, world, battle, menu.
- `entities`: player, NPC, Pokemon, item.
- `systems`: movement, collision, interaction, encounter.
- `maps`: loader, renderer, transition.
- `ui`: HUD, dialog, inventory, party.
- `api`: client gọi backend.

## Không làm trong tài liệu này

Chưa chuyển `map_viewer.html` sang framework mới và chưa thay đổi giao diện hiện tại.
