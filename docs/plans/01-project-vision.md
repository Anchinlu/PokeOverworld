# 01. Tầm nhìn dự án

## Trạng thái

Kế hoạch בלבד. Chưa triển khai.

## Mục tiêu

Xây dựng game 2D top-down lấy cảm hứng từ dòng game bắt quái vật, có bản đồ procedural, khám phá, NPC, nhiệm vụ, inventory, battle và lưu tiến trình.

## Nguyên tắc

- Tách frontend, backend, dữ liệu game và công cụ phát triển.
- Mỗi module có một trách nhiệm chính.
- Logic quan trọng nằm ở backend khi game có tính năng online.
- Dữ liệu game có version và có thể mở rộng.
- Chỉ triển khai từng phần sau khi có yêu cầu rõ ràng.

## Ngoài phạm vi hiện tại

- Chưa xây dựng gameplay mới.
- Chưa thay đổi code hiện có.
- Chưa chọn hoặc mua asset thương mại.
- Chưa quyết định mô hình multiplayer cuối cùng.
