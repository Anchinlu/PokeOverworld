# 06. Kế hoạch dữ liệu và database

## Trạng thái

Kế hoạch בלבד. Chưa triển khai.

## Entity dự kiến

- User.
- Player.
- Pokemon species.
- Player Pokemon.
- Move.
- Item.
- Player inventory.
- Map.
- Quest.
- Player quest.
- Battle.
- Save slot.

## Yêu cầu dữ liệu

- Có migration.
- Có version cho save game.
- Có audit field cho dữ liệu quan trọng.
- Không lưu dữ liệu gameplay quan trọng chỉ ở frontend.
- Có chiến lược backup và phục hồi.

## Chưa triển khai

Chưa tạo schema database, migration hay model ORM.
