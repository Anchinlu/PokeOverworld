# 10. Kế hoạch kiểm thử và chất lượng

## Trạng thái

Kế hoạch בלבד. Chưa triển khai.

## Các lớp kiểm thử

- Unit test cho terrain, collision, battle và inventory.
- Integration test cho API và database.
- Contract test giữa frontend và backend.
- End-to-end test cho login, save/load và gameplay chính.
- Visual test cho map và asset quan trọng.

## Kiểm tra tự động

- Lint.
- Formatter.
- Type checking.
- Test coverage.
- Validate game data.
- Build frontend và backend.

## CI dự kiến

Pull request phải chạy kiểm tra trước khi merge. Chưa tạo pipeline CI ở giai đoạn này.
